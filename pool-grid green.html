One-time setup needed

This page needs a free Firebase database plugged in before it can save anything. Open this file in a text editor and find the firebaseConfig object near the bottom of the page, then replace it with your own project's config. Steps:

  1. Go to console.firebase.google.com and create a free project (any Google account works).
  2. In the project, click the </> (web app) icon to register a web app, and copy the firebaseConfig object it gives you.
  3. In this file, go to Build > Realtime Database > Create Database, then open the Rules tab and set it to:
    { "rules": { ".read": true, ".write": true } }
    (This keeps things simple for a friend group — anyone with the link can read and write. Don't put anything sensitive in this board.)
  4. Paste your copied config into the firebaseConfig object in this file, replacing the placeholder values, and save.
  5. Re-host or re-upload the file wherever you're serving it from.
